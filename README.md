# 写字楼访客管理系统

一套基于微信小程序和云开发的写字楼访客预约管理系统，支持访客预约、审批流程、通行码核验和门禁设备对接。

## 功能特性

### 用户端功能
- **访客预约**: 填写访客信息、来访日期、被访人信息等
- **预约查询**: 查看我的预约记录和状态
- **通行码**: 审批通过后生成通行二维码
- **消息通知**: 预约状态变更时接收微信通知

### 管理端功能
- **审批管理**: 审批人审核访客预约申请
- **扫码核验**: 门卫扫描通行码进行身份核验
- **数据管理**: 查看、导出访客数据
- **设备管理**: 管理门禁/道闸设备

### 门禁对接
- 支持海康威视门禁设备
- 支持大华门禁设备
- 支持通用HTTP接口门禁
- 支持车牌识别道闸

## 快速开始

### 1. 环境准备

- 微信开发者工具（最新版本）
- 微信小程序账号（已开通云开发）
- Node.js 12+（本地开发用）

### 2. 配置云开发

1. 登录微信公众平台，开通云开发
2. 创建云开发环境
3. 记录云开发环境ID

### 3. 配置项目

1. 打开 `project.config.json`，替换 `appid` 为你的小程序AppID
2. 打开 `miniprogram/app.js`，替换 `env` 为你的云开发环境ID
3. 在微信公众平台配置服务器域名（如需要）

### 4. 部署云函数

1. 在微信开发者工具中，右键点击 `cloudfunctions/visitor` 文件夹
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 5. 创建数据库集合

在云开发控制台创建以下数据库集合：

- `users` - 用户表
- `visitors` - 访客预约表
- `gate_devices` - 门禁设备表
- `gate_records` - 通行记录表

### 6. 配置数据库权限

为每个集合设置数据权限：

- `users`: 仅创建者可读写
- `visitors`: 仅创建者可读写
- `gate_devices`: 所有用户可读，仅管理端可写
- `gate_records`: 所有用户可读，仅管理端可写

### 7. 运行小程序

1. 在微信开发者工具中编译运行
2. 使用测试账号登录体验功能

   - 模板内容：访客姓名、到达时间、被访人、所在楼层

## 常见问题

### Q: 如何设置审批人？
A: 在云开发控制台的 `users` 集合中，将用户的 `role` 字段设置为 `1`（审批人）。

### Q: 如何添加门禁设备？
A: 登录管理后台，进入"门禁设备"页面，点击"添加设备"按钮。

### Q: 通行码有效期是多久？
A: 默认为预约日期当天结束后24小时。

### Q: 如何导出访客数据？
A: 登录管理后台，点击"数据导出"按钮，系统会生成CSV文件供下载。
